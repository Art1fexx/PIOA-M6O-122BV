# Лабораторная работа №4 : Прототип СУБД с поддержкой долговременного хранения данных

## Германов Дмитрий/М6О-122БВ-25

Простая СУБД для управления данными об автомобилях с поддержкой двух типов хранения: in-memory (данные в оперативной памяти) и file-based (данные сохраняются в JSON-файлы).

## Реализованная функциональность

Проект представляет собой учебную реализацию системы управления базами данных (СУБД) с поддержкой:
- Создания таблиц с фиксированной схемой
- Добавления, просмотра, поиска, обновления и удаления записей
- Двух режимов хранения данных (in-memory и файловый)
- Сохранения данных на диск в формате JSON

### Требования
- Python 3.10 или выше
- Установленный pytest (для запуска тестов)

### Команда для запуска

Из корневой директории проекта выполните:

```bash
python -m PIOA-M6O-122BV.src.db

Для запуска всех тестов выполните из корневой директории:

bash
pytest tests/ -v

Для просмотра процента покрытия программы автоматизированными тестами:

python -m pytest --cov=src --cov-report=term-missing tests/

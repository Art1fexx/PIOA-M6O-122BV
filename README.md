## Реализованная функциональность

### Добавление записи
Пользователь последовательно вводит:
- Бренд (обязательное поле)
- Модель (обязательное поле)
- Год производства (целое число, от 1900 до 2026)
- Страна (опционально)
- Записи присваивается уникальный ID (целое число)

**Проверки:**
- ID не должен совпадать с существующим
- Год производства должен быть в диапазоне 1900-н.в.
- Бренд и модель не могут быть пустыми
- При успехе запись добавляется в таблицу и выводится на экран

### Просмотр
- Вывод всех записей таблицы в табличном виде

### Поиск
- Фильтрация записей по любому полю (ID, бренд, модель, год, страна)

### Обновление
- Изменение одного или нескольких полей существующей записи по ID

### Удаление
- Удаление записи по ID

## Реализованная функциональность

Добавление записи
Пользователь последовательно вводит:
- Бренд
- Модель
- Дата производства
- Страна

Просмотр - вывод всех записей таблицы

Поиск - фильтрация записей по любому полю (имя, фамилия, возраст, пол, ID)

Обновление - изменение одного или нескольких полей существующей записи по ID

Удаление - удаление записи по ID

**Проверки:**
- ID не должен совпадать с существующим (иначе `ValueError`)
- При успехе запись добавляется в таблицу и выводится на экран
